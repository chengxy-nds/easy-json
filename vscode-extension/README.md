# easyJSON for VS Code

专业级 JSON 智能提取、格式化、校验与语义对比工具。像 JSON 的字符串都能解析！

## ✨ 核心特性

- **右键选中文本即刻格式化**：在 VS Code 编辑器中选中任何文本/日志，右键选择 `easyJSON: 格式化/提取选中文本` 即可打开面板并自动提取。
- **智能格式提取**：支持 Java Lombok toString()、Python dict/repr、宽松 JS 对象、YAML、XML、CSV、MongoDB Shell、转义 JSON、混杂日志文本等 20+ 种格式。
- **4 大结构视图**：树形视图、代码高亮视图、脑图拓扑图谱、Excel 式表格视图。
- **语义级 Diff 对比**：智能过滤 Key 排序不同与缩进差异，精准对比字段值与类型变更。
- **完全本地离线**：数据 100% 本地内存解析，保障数据安全。

## 💡 使用方法

1. 在编辑区选中代码/日志文本 $\rightarrow$ **右键** $\rightarrow$ 选择 `easyJSON: 格式化/提取选中文本`。
2. 按 `Ctrl+Shift+P` (或 macOS `Cmd+Shift+P`) 呼出命令面板 $\rightarrow$ 输入 `easyJSON` 即可唤醒。
